# 精简控制台页面实现方案

该方案旨在精简“控制台”页面（HomeScreen），移除所有冗余元素，仅保留一个类似于手电筒开关的按钮，用于控制悬浮窗服务的开启与关闭。

## 用户审核事项

- **UI 变更**：首页（控制台）将不再显示功能介绍、模拟器入口和一键测试按钮。
- **交互方式**：点击中心的大型开关按钮将直接触发悬浮窗权限检查或切换服务状态。

## 拟定变更

### 界面逻辑 (UI Logic)

#### [MODIFY] [HomeScreen.kt](file:///media/daye/Data/Projects/表情包提取器/app/src/main/java/com/example/ui/screens/HomeScreen.kt)

- 移除 `HomeScreen` 中所有的 `Card`、`Text` 和 `FeatureTile` 等元素。
- 使用 `Box` 将内容居中。
- 实现一个自定义的“手电筒开关”按钮：
    - 大尺寸圆形按钮。
    - 根据 `state.isServiceRunning` 显示不同的颜色（开启为亮色/绿色，关闭为暗色/灰色）。
    - 按钮中心使用电源或手电筒图标。
    - 添加开启/关闭的状态文字提示。

## 验证计划

### 自动化测试
- 无

### 手动验证
1. 打开应用，进入“控制台”页面。
2. 观察页面是否仅剩一个中心大按钮。
3. 点击按钮，验证是否能正常开启/关闭悬浮窗服务。
4. 验证在未授予悬浮窗权限时，点击按钮是否能正确引导至系统设置页面。
